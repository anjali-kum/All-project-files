# All Project Files 🛠️

This repository contains a collection of various project files related to:

- ✅ Embedded Systems Development  
- ✅ Linux System Programming (LSP)  
- ✅ C Programming Practice  
- ✅ STM32 & ESP32 Projects  
- ✅ NRF SDK & Dashpod Modules  
- ✅ Raspberry Pi Snapshots  
- ✅ Peripheral Interfaces (SPI, I2C, UART, etc.)

---

## 📁 Folder Overview

Each folder in this repository represents a different project, module, or experiment. Some notable directories include:

- `C_PRACTICE` – Practice codes and basic programs in C.
- `kernal_programming` – Linux kernel-level programs and experiments.
- `ESP32CAM` – Projects for ESP32-CAM board.
- `Dashpod_modules_nrf_sdk` – Code related to Dashpod and Nordic SDK.
- `STM32-VACCUME`, `SDCARD_SPI_OLD_F103`, `DE-FIRMWARE-REFINED_*` – STM32-based embedded projects.
- `data_structure` – Data structures practice in C.
- `TA_BOOT_ANIMATION_1024X600` – Custom boot animation work for displays.

---

## ⚙️ Purpose

This repo acts as a centralized archive of all development and experimental projects done locally. It helps in:

- Keeping track of development progress
- Easy migration between systems
- Sharing and collaboration
- Backup and version control
